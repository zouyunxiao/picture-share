# 片刻 · Windows 原片导入助手

双击 `片刻导入助手/片刻导入助手.exe`。
请保留 EXE 旁的 `_internal` 文件夹，不要只复制一个 EXE。
当前目录与 `media-site` 网站目录放在同一个 `outputs` 目录中。

软件可在本地识别、预览照片和视频；导入后仍由现有公网网址对外展示。
本地预览不要求网站在线，上传需要原来的网站服务运行。

## 电脑文件夹 / iCloud 原片

1. 点击“选择原片文件夹”或“选择照片与视频”。
2. 软件检查照片和视频的内部实况标识，优先按标识匹配，标识不可用时按同名匹配。
3. 列表区分 LIVE、静态照片、普通视频和“实况 · 缺少动态”。
4. 选择一项查看封面，Live 图或视频可按住右侧预览区播放，松开恢复封面。
5. 点击“连接”。在当前电脑上，密码留空时可使用原网站的本地登录信息；
   也可以手动输入网站管理员密码。软件不另存密码。
6. 选择要导入的项目，点击“导入选中原片到网站”。

支持 HEIC/HEIF、JPEG、PNG、GIF、WebP、AVIF、MOV、MP4、M4V、WebM。
支持原生照片＋配对视频、含内嵌 MP4 的实况 JPG。影石专用工程格式需先从 App 导出为照片/实况原片或视频。
iCloud 中的文件需要完成原片下载；仅网页相册下载得到静态 JPEG 时仍没有动态视频。
请勿以录屏或重复帧代替原始动态，软件不会凭空生成丢失的视频。

## USB 从 iPhone 导入

1. 使用支持数据传输的 USB 线连接 iPhone，解锁并在手机上信任此电脑。
2. 建议在 iPhone 的“照片”设置中，把“传输到 Mac 或 PC”设为“保留原片”。
3. 切换到“iPhone USB 导入”，点击“刷新手机”，选择手机并点击“扫描手机原片”。
4. 选中需要的照片/视频，点击“导入选中原片到网站”。
5. 软件先复制所选原片到本机，核对文件大小，再检查内部标识并上传。
   手机上的照片和视频不会被删除或修改。

未连接手机、未解锁、没有信任电脑，或驱动不可用时，软件会提示。
必要时安装 Apple Devices；本软件不会自动安装驱动或更改系统设置。
iCloud 优化存储中的原片可能尚未在手机本地，需要先下载。
扫描手机阶段只能按文件名初步归组，复制到电脑后才检查内部实况标识。

**当前验证范围：** 已完成电脑端识别、配对、预览解码、上传接口和 EXE 打包验证。
当前没有连接真实 iPhone，因此 USB 原片枚举及复制尚待你接上手机后实测；
不能保证每种 iOS/Windows/驱动组合都可直接通过 Windows 设备接口读取。
若 Windows 不开放原片，可先用 Windows“照片”或 iCloud 下载到电脑，再走第一个入口。

## 本地数据

- 网站原有照片保存在 `media-site/data`；软件上传前后的原片不会被修改。
- USB 复制的原片保存在 `%LOCALAPPDATA%/MomentsImporter/originals`。
- 本地缓存默认保留，避免重复导入失败时丢失原片。确认网站和其他备份完成后，可自行管理。
- 取消会停止后续任务；正在进行的单个 USB 复制或网站转换可能完成后才停止。
- 软件只向本机 `127.0.0.1:8787` 的网站上传，不另建云相册。
- 网站仍按你原有设定公开展示；不要导入不准备公开的私人内容。

## 为什么微信可以，网页选择相册却丢了动态

iPhone Live Photo 包含照片与配对视频。原生 iOS App 可通过 Photos/PhotoKit
读取完整资源，而网页文件输入只能得到系统选择器实际提供的文件。
这次本站收到的部分 JPEG 保留了实况标识，但没有视频数据，因此无法长按播放。
桌面软件的作用是读取并保留完整原片；没有动态视频时，任何识别程序都无法还原原始动作。
微信具体内部代码未公开，这里说明的是原生应用可实现完整传输的技术路径。

开发者资料：
- https://developer.apple.com/documentation/photokit/phassetresource
- https://developer.apple.com/documentation/photokit/phassetresourcemanager
- https://support.apple.com/en-us/120267
- https://learn.microsoft.com/en-us/windows/win32/shell/folder-copyhere

## 源码

`source/app.py` 为 Windows 界面与本地预览，`source/core.py` 为原片识别和上传，
`source/usb-helper.ps1` 为只读枚举及复制手机原片的 Windows Shell 设备接口。
打包版包含 Python、HEIC 解码器及 FFmpeg，运行界面不需要另装 Python。
