# 片刻 · 本地影像网站

双击 `启动网站.cmd`，等待窗口显示公网访问地址，把地址发给别人即可访问。
本机也可以打开 http://localhost:8787。

点击网页右上角“管理空间”，使用 `登录信息.txt` 中的管理员密码登录。
登录后可选择多个文件或拖放上传，访客可浏览、预览和下载。
默认只有管理员能够上传和删除；网站中的所有已发布内容均可公开访问。

## 照片展示与拍摄时间

相册会逐张加载当前分类的全部缩略图，屏幕内优先，屏幕外也会继续加载，无需滚动触发。
采用单请求队列，前一张下载和显示完成后才加载下一张。
列表使用 640 像素范围的 WebP 缩略图，不直接下载整批原图；
打开详情先复用已加载的缩略图，同时优先下载当前清晰图，加载成功后替换；失败时保留缩略图。
当前清晰图加载完成后继续加载其余缩略图。切换时取消未完成的大图。
全部缩略图加载完后，会利用空闲网络逐张预加载详情图；新缩略图或当前大图优先。
预加载的详情图使用有限缓存，再次打开时直接复用；不会因为缓存淘汰而循环预加载。
Live 动态只在按住时请求，视频列表使用静态封面，避免自动读取所有视频的元数据。
原始照片不改动，“更多”中的下载仍提供原始文件。缩略图缓存在 data/thumbnails，可重新生成。
JPEG/HEIC 的网页静态展示图缓存在 data/previews；缩略图由该展示图缩小生成，使用同一主静态照片及 sRGB 色彩。
多图 JPEG 的辅助图层不作为动态片段，缺少动态的 Live 照片只展示主静态图；完整 Live 的动态仍只在按住时播放。

网页在电脑和手机上均为每行两张，连续展示，不显示页面大标题、日期大标题、
文件名或文件名搜索框。大图预览使用拍摄时间作标识，不显示文件名。

导入时优先读取原片 EXIF DateTimeOriginal 及其时区，
其次读取数字化时间或 XMP 中的原片时间；视频读取 QuickTime 拍摄/创建时间。
Live 图优先使用照片的拍摄时间。日期按原片记录保留，不因查看者所在时区而跨日。
列表按拍摄时间从新到旧排序，上传时间只保留作内部记录，不用于照片的拍摄时间排序。
缺少可靠原片时间的项目放在末尾，预览中标为“日期未知”；不会用上传时间或文件修改时间冒充。
服务升级时会重新读取已有原片补齐时间，不修改原片内容。

## 大图浏览

- 点开照片后，预览铺满浏览器可用窗口。照片保持原比例完整显示，不裁切；
  与窗口比例不一致的空余位置使用白色背景。点击照片外的白色留白或右上角 × 即可关闭。
- 左右滑动切换当前分类中的照片，也可点击左右按钮或使用键盘左右方向键。
  第一张与最后一张不会循环跳转。
- Live 图按住播放、松开恢复；横向滑动会切换照片，轻点不会被当成滑动。
- 轻点详情中的照片会留在当前详情页，不跳转到独立图片页面。
- 拍摄时间、序号和按钮浮在照片上；下载照片、动态视频及原始文件收在“更多”中。
- 关闭预览会回到相册原来的滚动位置。视频播放器底部的进度与播放控件保留正常操作。

支持 JPG、PNG、GIF、WebP、AVIF 图片，以及 MP4、WebM、MOV、M4V 视频。
也支持 HEIC / HEIF 图片与 Live 图，使用同一个上传入口自动识别。
单个文件最大 2 GB，以 8 MB 分片传输。视频不自动转码，
建议上传浏览器兼容性较好的 H.264/AAC 编码 MP4。
如果某个原始视频无法预览，可以下载后播放。

## Live 图

- 在同一个“选择文件”入口上传，或直接把一批文件拖入上传区域。
- iPhone / 影石导出的实况原片：选中保留配对关系的照片与视频，
  例如 `IMG_1234.HEIC` + `IMG_1234.MOV`，也支持 JPG + MP4。
  会自动合并为一张 Live 图，顺序不限，也支持后续分批补传。
  优先按照片 Apple MakerNote 和视频中的原生实况标识配对，
  标识不可用时再按同名配对；标识冲突或候选不唯一时不会猜测。
- 含内嵌 MP4 动态片段的实况 JPG 可单独上传并自动识别。
- 单独上传 HEIC 会转为浏览器可显示的 JPEG；单独上传视频仍作为普通视频。
- 只有静态照片时无法还原动态。手机相册选择器或“兼容格式”导出可能只给网页静态图，
  请通过导出未修改的原片等方式保留照片和 MOV 两部分，并在同一批选择上传。
- 文件名不同但原生实况标识相同也可以配对；若导出过程移除了标识，
  请保留导出原片的同名关系。
- 对带实况标识、但没有视频的照片，网页直接按普通照片展示，
  不显示缺少动态的角标或提示。只有照片和动态部分齐全的 Live 图显示 LIVE 图标并支持长按播放。
  后台仍保留配对信息，已上传照片无需重复上传，补传匹配 MOV 即可自动合并。
- 从 iPhone 浏览器的相册选择器直接选择实况照片时，可能只交给网页静态 JPEG。
  网页无法从这份 JPEG 还原未上传的视频。需要导出并上传保留照片与 MOV 的原片，
  或使用能够读取完整 Live Photo 资源的原生 iOS 上传端。
- 仅用 iPhone 补传的一种办法：在“照片”中打开一张实况图，
  右上角“…” →“存储为视频”。把生成的视频分享到“文件”，
  保留扩展名并改成与已有照片相同的基础名称，再从网站同一个入口上传视频。
  此方式使用导出视频生成网页 Live 图，不会把静态照片凭空还原成原始动态。
- Live 图卡片左上角有 LIVE 标记。按住约 0.22 秒开始播放；松开、
  手指移出、滚动或切换到后台时恢复封面，再次长按从头播放。
- 短按打开大图，大图中同样可以长按。电脑可用鼠标按住，也可聚焦后按住空格或回车。
- 动态默认静音，转成 H.264 MP4 供浏览器播放；不会改变保留的原始照片和视频。
- 大图下方可下载照片、播放用动态视频，以及原始文件。
- 同名组合、内嵌 JPG、Apple MakerNote 标识与 MOV 标识的分批配对已测试。
  已检查本站实际上传的照片：部分保留了实况标识，但没有视频数据。
  具体相机、App 的私有原始格式需先导出成上述照片 / 视频格式。
- 自动合并时，原有文件额外保留在本机备份中，合并历史记在 `data/merged-history.json`；
  网页下载的原始文件仍来自本次合并保留的原片。

Live 图处理依赖 Python 3.12 和项目 tools/python 中的 Pillow、pillow-heif、
imageio-ffmpeg（含 FFmpeg）。当前电脑已配置；如果重新部署到另一台电脑，
请使用 `python -m pip install --only-binary=:all: --target tools/python -r requirements-live.txt` 安装。

## 日常使用

- 电脑需保持开机和联网，网站服务与隧道需要保持运行。
- 当前使用 Cloudflare 免费临时隧道，重新启动隧道后网址可能变化。
- 最新网址保存在 `公网地址.txt`，管理员密码保存在 `登录信息.txt`。
- 双击 `停止网站.cmd` 可关闭网站及公网入口，已上传内容仍保留。
- 未配置开机自动启动。
- 文件保存在 `data/files`，目录索引在 `data/library.json`。
  备份时请备份整个 `data` 文件夹。
- 不要将整个项目文件夹或 `登录信息.txt` 分享给访客，只分享网址。
- 网页删除会删除本地原文件，操作前网页会要求确认。

## 固定网址

当前测试链接不需要购买域名。长期使用固定网址，可绑定自己域名，
在 Cloudflare 账户创建正式 Tunnel，并把流量转到 `http://127.0.0.1:8787`。
正式域名需要你的域名和账户配置。

## 技术信息

Node.js 原生 HTTP 服务，无 npm 依赖。服务只监听本机 127.0.0.1:8787，
公网访问经 Cloudflare Tunnel 转发。不需要路由器端口映射。
管理员密码以 scrypt 加盐哈希保存；登录会话有效期 12 小时，
重启服务后需要重新登录。上传接口需要管理员会话，文件名不会用于磁盘路径。
网页使用安全响应头、同源检查和文件格式检查。
